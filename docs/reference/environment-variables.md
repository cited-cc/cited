# Environment variables

Community edition configuration reference. Values shown are placeholders. Never commit real secrets.

Secret file support: many variables accept `VARIABLE_FILE` pointing to a file containing the secret value.

## Deployment and auth

### `CITED_DEPLOYMENT_MODE`

| | |
| --- | --- |

| Default | `self_hosted` in community examples |
