# Feature matrix

Truthful comparison between the open-source community edition and optional [Cited Cloud](https://cited.cc). Cloud functionality and plans may change independently of this repository.

| Capability | Community edition | Cited Cloud |
| --- | --- | --- |
| Self-hosting | Yes | Managed |
| Citation monitoring | Yes | Yes |
| Competitor tracking | Yes | Yes |
| Evidence ledger | Yes | Yes |
| Inbox and notebook | Yes | Yes |
| DataForSEO adapter | Bring your own credentials | Managed (operator-provided infrastructure) |
| Scheduling | Self-hosted worker | Managed |
| Email notifications | SMTP (operator-configured) | Managed email delivery |
| Slack notifications | Configurable per workspace | According to current Cloud availability |
| Infrastructure support | Community | Managed |

## Not framed as paywalls

Self-hosted safety limits (users, domains, monitors) are operational controls, not commercial upsells. Cloud billing and checkout are not part of the community edition.
