# Citations and mentions

Cited classifies monitored responses into event types you can review in the inbox and notebook.

## Event types

| Type | Meaning |
| --- | --- |
| **Citation** | Verified domain or brand appears with a source URL |
| **Mention** | Brand name appears without a matching source URL |
| **Recommendation** | Brand recommended in response context |
| **Competitor citation** | Tracked competitor domain cited |
| **Missed opportunity** | Competitor cited while your verified domain was absent on a related prompt |

Classification depends on response content and your domain verification state.

## Confidence

Each event includes a confidence score and evidence snippets. Review low-confidence events before acting on them.

## Mock labeling

Mock provider events include `[MOCK]` prefixes in titles and snippets. Never treat mock output as live AI evidence.
