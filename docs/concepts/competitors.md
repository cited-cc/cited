# Competitors

Track competitor domains to detect when they appear in monitored AI responses.

## Setup

1. Add competitor hostnames in workspace settings
2. Enable competitor alerts in notification preferences
3. Run monitors on prompts where competitive presence matters

## Event types

| Event | When it fires |
| --- | --- |
| Competitor citation | A tracked competitor domain is cited |
| Missed opportunity | Competitor cited while your verified domain was absent |

## Fictional examples

Demo and mock data uses reserved domains such as `competitor-labs.example`. Do not use real customer domains in fixtures.
