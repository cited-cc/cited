# Roadmap

This roadmap lists **directional** public milestones for the Cited open-source
core. Items are goals, not promises, and may change without notice.

Publication remains blocked until Phase 16 release approval.

## Current capabilities (community edition)

- Self-hosted Docker Compose with PostgreSQL 17, web, and worker
- Local authentication and first-owner bootstrap
- Mock provider with fictional demo data
- DataForSEO adapter with bring-your-own credentials
- Citation monitoring, competitor tracking, evidence ledger, inbox, and notebook
- SMTP and Slack notification adapters
- Documentation, CI quality gates, and publication readiness checks

## Milestones

### Documentation and contributor experience

**Phase 15 complete.** README, documentation index, quickstart, reference docs,
brand assets, screenshot workflow, and documentation CI validation.

### First stable release (Phase 16)

- Public Git repository and remote validation
- CI execution on GitHub Actions
- Release tag and branch protection
- Container image publication (when approved)

### Provider adapters

Expand and harden monitoring provider adapters with bring-your-own credentials.

### Monitoring correctness

Improve scheduling, evidence capture, and classification reliability across
supported surfaces.

## Non-goals for this document

- Private Cited Cloud commercial plans or pricing
- Outreach, lifecycle, or hosted-only operations detail
- Guaranteed delivery dates

See [docs/open-source/publication-boundary.md](docs/open-source/publication-boundary.md)
for scope boundaries.
