# Support

## Project status

This repository is a pre-release open-source candidate. Publication and
community support channels are not fully enabled yet.

## Bug reports

After the repository is published, use GitHub Issues for reproducible bugs.
Include environment details and sanitized logs. See the bug report template.

Do not include secrets, tokens, customer data, or personal information.

## Questions and ideas

After GitHub Discussions is enabled, use Discussions for general questions and
integration help.

Until then, non-security questions may be directed to https://cited.cc/contact.

## Security issues

Security vulnerabilities must **not** be reported in public issues.

Follow [SECURITY.md](SECURITY.md) for private reporting.

## Self-hosting support

Self-hosting documentation and deployment tooling are incomplete in this phase.

Community support for self-hosted deployments is best-effort unless a separate
commercial agreement states otherwise.

## Cited Cloud

Hosted Cited at cited.cc is a separate product with its own support terms.
Open-source repository support does not imply Cited Cloud service-level
commitments.

## Response times

No response time guarantees are implied for community support, pre-release
candidates, or unsolicited reports.

## Commercial support

Commercial support or enterprise agreements may be offered separately in the
future. No pricing or terms are published in this phase.
